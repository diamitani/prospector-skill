The 5-Pillar Outbound Architecture

Engineered to replace fragile scraping hacks with unbreakable, deterministic research engineering.

01

PAL Intent Ingestion

Converts natural language mission briefs into strict, structured research plans. Establishes hard boundaries, role tiers, and zero-spend constraints before execution.

  • ✓ Reversible Defaults ($0 budget, 60 max queries)

Observable Signal Discovery

Replaces assumptions with falsifiable market triggers. Finds companies actively hiring target roles, expanding products, or announcing funding.

  • ✓ Dated job postings & funding events
  • ✓ Official domain canonicalization & deduping
  • ✓ 30 & 90-day strict freshness windows
03

Pinpoints exact functional owners and decision makers without violating LinkedIn scraping terms. Queries corporate team pages and public announcements.

  • ✓ Tier 1 Decision-Maker prioritization

04

RFC-7505 DNS MX Triage

Eliminates wasted API quota and invalid mailboxes by verifying DNS routing states once per unique domain before candidate generation.

  • ✓ Null MX (0 .) immediate rejection
  • ✓ NXDOMAIN & dead host drop
  • ✓ Implicit A/AAAA RFC-5321 fallback support
05

Safety Gate & Scoring

Enforces VERIFY_DISCLOSURE approval tokens before transmitting any payload to Hunter, computes 0–100 quality scores, and compiles audit reports.

  • ✓ Hunter free-tier quota protection
  • ✓ Lexicographical 0–100 scoring engine
  • ✓ Quarantines Catch-Alls to needs_review

Frequently Asked Questions

Everything you need to know about the Prospector PAL engine and .skill distribution.

How is Prospector PAL different from Apollo or ZoomInfo?

Traditional data brokers sell stale, pre-scraped contact databases with high bounce rates. Prospector PAL is an autonomous research engine that evaluates real-time, observable buying signals (current job postings, funding news), parses identity, checks live DNS MX routing, and tests verification with zero runaway spend.

Where can I upload the .skill file?

The .skill package is formatted as a universal agent skill archive. You can load it into Google Antigravity, Claude Desktop, Cursor, OpenDevin, Anthropic Agent Harness, or run the embedded Python scripts locally.

How does the Zero-Spend Guarantee work?

All discovery queries utilize free search adapters and public DNS lookups. Email verification uses free Hunter account quotas. If free quotas are reached, the system flags the lead as not_checked rather than incurring spend.

What is RFC-7505 Null MX Triage?

RFC-7505 defines a standard for domains that explicitly publish MX 0 . to state they accept no email. Prospector PAL tests for this immediately, rejecting invalid candidates before risking sender reputation or API credits.
